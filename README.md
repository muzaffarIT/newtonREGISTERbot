# Asalya Bot: Newton Academy

Телеграм-бот для автоматического распределения учеников по языковым группам в учебном центре Newton Academy на базе Google Sheets API. Бот парсит анкеты менеджеров, подбирает группу с учетом филиала, класса, языка и времени занятий, после чего обновляет статистику заполняемости кабинетов.

## 🚀 Архитектура и функции
Проект написан на базе `aiogram` 3.x и `gspread` с использованием `tenacity` для отказоустойчивости взаимодействия с Google API.
Google-запросы выполняются неблокирующе через `asyncio.to_thread`.
Используется механизм `asyncio.Lock()`, исключающий "состояние гонки" (race conditions) при одновременной записи нескольких учеников на последнее свободное место.

## ⚙️ Установка

1. **Клонируйте репозиторий** и перейдите в его директорию:
   ```bash
   git clone <url_репозитория>
   cd asalya_bot
   ```

2. **Создайте виртуальное окружение** и активируйте его:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Для macOS/Linux
   # .venv\Scripts\activate   # Для Windows
   ```

3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте переменные окружения**:
   Скопируйте пример файла `.env`:
   ```bash
   cp .env.example .env
   ```
   Внутри `.env` укажите:
   - `BOT_TOKEN` — токен бота от @BotFather.
   - `SPREADSHEET_ID` — ID вашей таблицы Google Sheets.
   - `GROUP_CHAT_ID` — ID группы менеджеров.
   - `CREDENTIALS_FILE` — Имя файла (или путь к файлу) конфигурации сервисного аккаунта (по-умолчанию `credentials.json`).

5. **Настройте Google API**:
   - Положите в корень проекта файл `credentials.json` (ключ сервисного аккаунта Google Cloud Platform с доступом к Sheets API).
   - Убедитесь, что таблица расшарена на email сервисного аккаунта (`client_email` в JSON-файле) с правами "Редактор".

## 🏎️ Как запустить

**Локальный запуск (тестирование)**:
```bash
python bot.py
```

**Деплой на Railway**:
Проект полностью готов для деплоя на Railway или Heroku.
- Файл `Procfile` содержит команду запуска `worker: python bot.py`.
- В Railway необходимо загрузить переменные из `.env`. Файл `credentials.json` нужно либо скопировать, либо подставлять на старте через скрипт `Base64` (но для простоты можно включить его в приватный репозиторий GitHub).

## 📄 Основные команды бота:
- `/groups [Филиал]` — статистика по группам, количество мест и заполненность.
- `/students [Филиал]` — вывод списка записанных учеников за всё время.
- `/waiting [Филиал]` — лист ожидания, если мест в группе не было.
- `/stats` — общая статистика по заполненности и свободным местам во всех филиалах.
- `/search [Имя]` — поиск ученика по имени (среди студентов и листа ожидания).
- `/report` — генерация ежедневной сводки (отчет за сегодня).
